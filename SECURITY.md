# Security Policy

Thanks for helping improve the security of Snap.

## Supported Versions

The following versions are currently supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.17.x  | :white_check_mark: |
| < 0.17  | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities in Snap privately, through the [GitHub vulnerability reporting tools](https://github.com/breakroom/snap/security/advisories).
